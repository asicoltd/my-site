SYSTEM // RES-01

Explainable IoT Intrusion Detection & DTN Optimization

Investigates opportunistic communication reliability and attack detection across Delay-Tolerant Networks (DTN) in communication-compromised disaster scenarios using the ONE simulator.

  • Analyzed packet drop and blackhole attack topologies in partitioned ad-hoc environments.
  • Coupled network simulation with gradient-based feature attribution to expose anomalous routing decisions.
  • Simulated realistic urban catastrophe mobility models for autonomous emergency node triage.

Multi-agent reinforcement learning execution engine examining non-stationary temporal dynamics and cross-asset price propagation across algorithmic financial markets.
